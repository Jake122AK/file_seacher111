# MIDNIGHT MUSHROOM DRIVE — Stage 1

**Psychedelic Pixel Driving Rhythm Game** / スマートフォン縦画面 / 約4分52秒1本勝負

普通に車で家を出ただけだったのに、5分後には宇宙の果てで
フラダンサーと巨大な猫と踊りながら虹の道路を走っている。
——その体験を、外部依存ゼロの HTML5 + Canvas で実装したものです。

```
psychedelic-drive/
├── index.html            開発用（src/ を個別に読む）
├── dist/
│   └── psychedelic-drive.html   1枚完結版（これをスマホで開けば動く）
├── build_single.py       ↑を生成するスクリプト
├── data/                 ★コンテンツ層（ここだけ書き換えれば別ステージ・別曲になる）
│   ├── track_default.js  BPM / 拍 / セクション / ドラムグリッド / 譜面ルール
│   └── stage1.js         約4分50秒のタイムライン（世界・道路変形・エフェクト）
└── src/                  ★エンジン層（ステージ固有の記述を一切持たない）
    ├── core.js           数学 / カラーパレット / 3x5ビットマップフォント
    ├── pixel.js          低解像度ピクセルバッファ + ポストエフェクト
    ├── audio.js          WebAudio音楽エンジン + Conductor（音楽時計）
    ├── input.js          片手ドラッグステアリング / ジャイロ（任意）
    ├── art.js            ドット絵アセット + モーフィング可能な描画関数
    ├── world.js          ワールド重みブレンド / 多重パララックス / 路肩オブジェクト
    ├── road.js           譜面 + 擬似3D道路レンダラ + 判定
    ├── scenes.js         導入（家）と終幕（帰宅）
    └── game.js           進行 / トリップ管理 / スコア / ダッシュボード / HUD
```

## 遊び方

`dist/psychedelic-drive.html` をスマホのブラウザで開くだけ。
（サーバー不要。`file://` でも動きます）

1. 夕方のリビング。テーブルの上の**キノコをタップ**すると主人公が食べる。
2. 数秒間、本当に何も起こらない。やがて家を出て、車に乗り、エンジンをかける。
3. **画面を左右にドラッグ**して車を操作。視点は三人称で、自車が常に見えます。
   道路の曲線を車でなぞり続けるのが「上手いプレイ」。
   カメラは自車に少し遅れて追従するので、曲がるほど自車が画面内で左右に振れ、
   自分がどのラインを通っているのかが一目で分かります。
4. 失敗してもゲームオーバーにも事故にもならない。
   MISS すると少し道を外れ、世界がグニャッと歪み、自然に戻される。

キーボード（PC確認用）: `←` `→` で操舵、`Space` でタップ。

### 開発・プレビュー用

| 操作 | 内容 |
|---|---|
| `?skip=1` | 導入シーンを飛ばして 0:00 からドライブ開始 |
| `?t=105` | 任意の秒数から開始（例: 南国突入直後） |
| `PX.game.seek(255)` | コンソールから任意の時刻へジャンプ |
| `PX.game.trip` | 現在のトリップレベル / グルーヴ率 |

## 中核アイデア：道路そのものが譜面

上から降ってくるノーツUIは存在しません。

> 距離 `dz` 先の道路中心 = 「`dz / 速度` 秒後の譜面レーン値」

という定義になっているため、**前方の道路を見ること＝未来の譜面を読むこと**です。
ハンドルを曲線の中心に合わせ続けることが、そのまま正確な演奏になります。
矢印やノーツを別途表示する必要がないので、プレイヤーの視線は常に世界に向きます。

判定は `PERFECT / GROOVY / GOOD / MISS` の4段階。表示は小さく一瞬だけ。
低音では路面が上下にうねり、強いビートでは道幅が脈動し、
スクラッチ的な区間では譜面が `snap`（急激な左右操作）になります。

## グルーヴ率でトリップ内容が分岐する

この作品固有の仕組みです。判定精度から `groove (0..1)` を作り、次の3つを同時に動かします。

| groove | 効果 |
|---|---|
| トリップレベル | 最大 **+1.7 / −1.3** レベルが上下する |
| ワールド重み | タイムラインの `worlds` から **`deep`（深い版）** へブレンドされる |
| 路肩の密度 | フラダンサーなどの出現数が最大 **3.4倍**（実測: 66体 → 361体） |

つまり **音ゲーの腕前 ＝ どこまで深い世界を見られるか**。
上手いと南国の途中で宇宙が滲み出してきますが、ミスが続くと現実寄りに引き戻されます。
リザルトの `TRIP DEPTH` が到達した最深部です。

## 約5分の構成

| 時刻 | フェーズ | 内容 |
|---|---|---|
| 0:00–0:35 | **NORMAL** | 完全に普通の住宅街。夕焼け、電柱、家、街路樹。0:15/0:21/0:27 に**同じ猫が3回**現れる。信号の色が一瞬だけ紫になる |
| 0:35–1:00 | **SOMETHING IS WRONG** | 道路が音楽的に曲がり始める。街灯がビート同期。標識の `STOP` が `DANCE` に化ける。家の窓が目のようにまばたきする |
| 1:00–1:37 | **TRIP START** | 月がこちらを見る。雲が顔になる。道路が虹色を帯び、建物が呼吸を始める |
| 1:37–1:43 | **TUNNEL** | 突然トンネル。暗闇。天井灯だけが流れる |
| 1:43–2:25 | **PARADISE** | 出口はもう完全な南国。ヤシ、フラダンサー（進むほど増殖）、サングラスの太陽、空を泳ぐ魚とクジラ |
| 2:25–3:20 | **COLLAPSE** | 南国 → 宇宙 → 巨大都市 → ジャングル → 海底。カット割りせず**モーフィング**で繋ぐ |
| 3:20–4:11 | **PSYCHEDELIC ZONE** | 巨大な目、万華鏡、螺旋、鍵盤化した道路、浮遊島、空から降るレコード |
| 4:11–4:33 | **CLIMAX** | 全ワールドが重なる。虹色の一本道。全キャラが同じビートで踊る。PERFECT でドットの花火 |
| 4:33–4:52 | **RETURN** | 白い光。夜の住宅街。音楽が消えてエンジン音だけ。家の前で停車。数秒、何も起こらない。——最後に道路脇の**最初と同じ猫だけが一瞬虹色に点滅**して、暗転 |

タイムラインは `data/stage1.js` の秒、音楽は `data/track_default.js` の小節で管理しています。
両者は **1小節 = 2.857秒（84BPM / 4拍）** で 1:1 対応しているので、
尺を変えるときは両方を同じ比率で動かしてください。

## トランジション設計（暗転で切り替えない）

世界は「切り替える」のではなく「重みを移す」構造になっています。

* **パレット** — 全ワールドが同じスロット名を持つので重み平均するだけで色が連続的に溶ける
* **背景レイヤー** — 重みをそのままアルファに。山が薄れながらビル群が浮かび上がる
* **路肩オブジェクト** — 種別（`flora` / `house` / `figure` …）しか持たず、見た目は
  **毎フレーム現在のワールド重みから決まる**。だから *すでに生えている街路樹がその場でヤシの木に変わり、さらに先端が星になって宇宙へ繋がる*

`art.js` の `PX.draw.tree(p, x, base, h, m, …)` の `m` が `0 → 1 → 2` と動くと
**広葉樹 → ヤシ → 星** に連続変形します。建物も `m` で 一軒家 → 高層ビル、
`melt` で 窓 → 星 に変わります。これがモーフィングの実体です。

## 実楽曲の入れ方

現状は完成楽曲なしで動くよう、WebAudio でレゲエ／ダブ風の仮トラックを合成しています。
差し替えは `data/track_default.js`（またはコピーした新ファイル）だけで完結します。

```js
window.PX.TRACKS.default = {
  bpm: 84,                 // ← 実曲のBPM
  beatsPerBar: 4,
  offset: 0,               // 曲頭の無音ぶんのオフセット（秒）
  audioUrl: 'music/my_dub_track.mp3',   // ← これを指定すると合成音は自動停止し、
                                        //    音源の再生位置が Conductor の時計になる
  chart: [                 // ← 譜面を固定したい場合。省略時は下の style から自動生成
    { beat: 0,   lane: -0.6, kind: 'ease'  },   // lane: -1..1（道路の曲がる方向と量）
    { beat: 2,   lane:  0.8, kind: 'snap'  },   // kind: ease / snap / hold / swing
    { beat: 4,   lane:  0.8, kind: 'hold'  },
  ],
  sections: [
    // bar: 開始小節 / energy: 0..1 / pattern: 演奏パターン名
    // style,amp: chart 省略時の譜面自動生成ルール
    { name:'INTRO', bar:0,  energy:.1, pattern:'intro', style:'still',  amp:.2 },
    { name:'DROP',  bar:76, energy:.9, pattern:'tropicalA', style:'skank', amp:.8 },
  ],
  patterns: { /* 16分グリッド。'x...x...x...x...' 形式で書ける */ }
};
```

**`patterns` のドラムグリッドは音を鳴らすだけのものではありません。**
「いつキックが鳴るか」を視覚側のエンベロープ源としても使っているため
（`Conductor.env.kick / snare / hat / bass`）、実音源に差し替える場合も
グリッドだけは書いておくと、**道路の脈動・街灯の明滅・建物の呼吸・空の色**が
音源と完全に同期します。音声解析は不要です。

譜面自動生成の `style` は `still / straight / sway / skank / long / scratch / wave / wild / climax` から選べます。
`skank` はレゲエの裏拍でクイッと寄せる動き、`long` は長いカーブ、`scratch` は急激な左右操作になります。

## Stage 2 以降の作り方

`data/stage1.js` を複製して `keys[]` を書き換えるだけです。エンジン側の変更は不要です。

```js
{ t: 300,                                  // 秒
  level: 7.0,                              // トリップレベル 0..10
  worlds: { tropical: .55, space: .45 },   // ワールド重み（正規化される）
  deep:   { tropical: .35, space: .65 },   // グルーヴが高い時に寄る“深い版”
  warp:  { rainbow:.55, glow:.9, wave:.4, sky:.12, spiral:0, loop:0, keys:0, liquid:.25 },
  fx:    { sat:.55, rgb:.3, wave:.32, trails:.34, kaleido:.1, melt:0, posterize:0 },
  v:     { speed: 40, signSet:'deep', starBoost:.6, moonFace:1, cloudFace:1 } }
```

`events[]` は一度きりのトリガです
（`cat` / `hueBlip` / `whoosh` / `tunnelIn` / `tunnelOut` / `thirdPerson` /
`mirrorWorld` / `fireworks` / `whiteout` / `musicOut`）。

> **`fx` の値は 0..1 の「許容範囲のうちどれだけ使うか」**です。
> 実際の振れ幅は `src/game.js` の `FX_MAX` がエンジン側の責任として決めています。
> だからデータ側は終盤に思い切って `1.0` と書けますし、
> それでも **走行ラインが読めなくなることはありません**。

## 「エフェクトのインフレ」と可読性の両立

序盤 0〜5%、中盤 30〜50%、終盤 100%、帰還した瞬間に 0 へ——という設計ですが、
全部を全画面に掛けると道路が消えてゲームとして成立しなくなります。
そこで **走行ライン保護マスク** を入れてあります。

`pixel.js` のポストパスは行ごとに `mask[y]` を持ち、地平線より下では
万華鏡・トンネル・回転・ズーム・メルトの効きを最大 90% 落とします。
結果として **サイケデリアは空で暴れ、道路は常に読める**状態になります
（副次的に、重い極座標演算が画面の約半分でスキップされ高速化にも効いています）。

## パフォーマンス

内部解像度 192px 幅の低解像度バッファに描画し、整数倍でニアレストネイバー拡大しています
（＝本物のドット絵。3Dモデルは一切使っていません）。

* 幾何 / 色 / 残像の3パスを **1パスに融合**
* 極座標演算（万華鏡・トンネル）は空の領域のみ
* スプライトの揺れは行単位ではなく最大6バンド
* 極座標変形は 3px おきに計算して線形補間（見た目は同じで transcendental が 1/3）
* 道路の行ごとの色は 3 行ごとにだけ作り直す（確保と文字列生成が 1/3）
* 路肩オブジェクトは近い順に最大 150 個で打ち切り
* **自動品質調整** — 実処理時間に応じて内部解像度を 192→176→160→144 と上下させる

**自動品質は内部解像度を主レバーにしています。** 実測すると、エフェクトを削るより
解像度を1段落とす方がはるかに効くためです（クライマックスで 192px:29fps → 160px:45fps）。
フレームごとの実処理時間を測り、14ms を超えたら 192→176→160→144 と1段ずつ下げ、
9ms を下回ったら1段ずつ戻します。rAF の間隔は vsync で 16.7ms に張り付いて
「余裕があるか」が判定できないので、**間隔ではなく実処理時間**で測っているのが要点です。
エフェクト側の減衰は 60% までに留めてあり、終盤の絵作りは壊れません。

参考値（Chromium / 390x844 / デスクトップ / 自動品質が落ち着いた後）:
全区間 58〜60fps。以前は終盤が 29fps まで落ちていました。

## カメラと自車

視点は**三人称**です。カメラは自車の横位置に **58% の追従率**で遅れてついていくので、
ハンドルを切ると自車が画面内で左右に振れます。これによって
「今どのラインを走っているか」「次のカーブに対してどれだけズレているか」が
車の位置そのもので読めるようになっています。

自車は `art.js` の `PX.draw.carRear()` がプロシージャルに描いています。
すべての寸法を「画面上の半車幅」基準にしているので、遠近で拡大縮小しても比率が崩れません。
ステアリングでキャビンが傾き、キックでサスペンションが沈み、
テールランプがビートで光り、排気煙が後ろへ流れます。

`closeUp` イベント中だけカメラが車に寄って見上げる画になります。

## オブジェクトの遠近と配置

* **建物は正面 + 側面 + 屋根**で描いています（`PX.draw.building2`）。
  側面は消失点へ向かって後退し、そこにも窓が並ぶので奥行きが出ます。
* **建物は「道路側の内側エッジ」を基準に配置**し、必ず外側へ伸ばします。
  高層化しても巨大化しても、道路にはみ出しません。
* **近距離フェード**を種別ごとに変えています。大きい物（建物・浮島・モノリス）は
  早めに消し、小さい物（人・木・標識）は近くまで残します。
  これが無いと、巨大化した建物が至近距離で画面を塞ぐ「壁」になります。
* **樹木は3種類**（広葉樹・針葉樹・ポプラ）を種で選び、暗部→明部→リムライトの
  順に重ねて立体感を出しています（`PX.draw.tree2`）。
* **キャラクターは配色違いを含めて9種類**（フラダンサー3色・通行人3色・子ども・
  ローブの人物・宇宙人・二足歩行の猫）。個体ごとに種を持つので毎フレーム同じ姿です。

## 実装メモ

* 外部リソース・外部通信は一切なし。画像もフォントもすべてコード内で生成しています
  （3x5 ビットマップフォント、文字列アートからのスプライト生成 + 色相バリアント事前生成）
* 音は全て WebAudio による合成（キック／スネア／ハット／ベース／スキャンク／パッド／
  ダブディレイ／エンジン音／SE）。AudioContext はキノコのタップで起動します
* ジャイロ操作は `PX.game.input.enableGyro()` で有効化できます（iOS は許可ダイアログが出ます）
* 音が鳴らない環境でも内部時計にフォールバックしてゲームは最後まで進行します
